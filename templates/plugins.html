Install Community Plugin from ZIP

A plugin ZIP must contain a manifest.json at its root and a Python entry-point file.

Creating a Community Plugin
  1. Create a folder: plugins/community/my_plugin/
  2. Add manifest.json: 
    {
  "id":          "my_plugin",
  "name":        "My Plugin",
  "version":     "1.0.0",
  "author":      "Your Name",
  "description": "What this plugin does.",
  "entry":       "plugin.py",
  "hooks":       ["on_atc_response", "on_telemetry"]
}
  3. Add plugin.py: 
    from core.plugin_api import OpenFrequencyPlugin

class Plugin(OpenFrequencyPlugin):
    def on_load(self):
        self.log("Hello from my plugin!")

    def on_atc_response(self, text, action):
        # Optionally modify ATC text; return None to keep original
        return None

    def on_telemetry(self, data):
        alt = data.get("aircraft", {}).get("altitude", 0)
        # do something with altitude…
  4. Restart OpenFrequency or click Reload Plugins.
