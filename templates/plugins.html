从 ZIP 安装社区插件

插件 ZIP 根目录须包含 manifest.json 和 Python 入口文件。

创建社区插件 / Creating a Community Plugin
  1. 创建文件夹 / Create folder: plugins/community/my_plugin/
  2. 添加 / Add manifest.json: 
    {
  "id":          "my_plugin",
  "name":        "My Plugin",
  "version":     "1.0.0",
  "author":      "Your Name",
  "description": "What this plugin does.",
  "entry":       "plugin.py",
  "hooks":       ["on_atc_response", "on_telemetry"],

  "cabin_media": [
    {
      "id":          "boarding_music",
      "label":       "登机音乐 / Boarding Music",
      "type":        "audio",
      "src":         "media/boarding.mp3",
      "callsigns":   ["CCA", "CSN", "CHH"]
    },
    {
      "id":          "safety_video",
      "label":       "安全演示视频 / Safety Demo",
      "type":        "video",
      "src":         "media/safety.mp4",
      "callsigns":   []
    }
  ]
}
    cabin_media — 定义插件提供的客舱媒体（音频/视频）。callsigns 数组填入呼号前缀（如 "CCA"）可实现按航司自动匹配；留空 [] 表示通用媒体，对所有呼号可见。
    媒体文件路径相对于插件目录。编译版本中请将媒体文件放入插件文件夹内。
  3. （可选）添加客舱脚本 / Add cabin scripts — 在插件目录下创建 cabin/scripts.json，格式与内置 data/cabin/scripts.json 相同，可扩展机舱广播文本。
  4. 添加 / Add plugin.py: 
    from core.plugin_api import OpenFrequencyPlugin

class Plugin(OpenFrequencyPlugin):
    def on_load(self):
        self.log("Hello from my plugin!")

    def on_atc_response(self, text, action):
        # Optionally modify ATC text; return None to keep original
        return None

    def on_cabin_media_play(self, media_id):
        # Called when user plays a cabin media item defined in this plugin
        self.log(f"Playing cabin media: {media_id}")

    def on_telemetry(self, data):
        alt = data.get("aircraft", {}).get("altitude", 0)
  5. 重启 OpenFrequency 或点击「重载所有插件」/ Restart or click Reload All Plugins.
可用钩子 / Available Hooks
Hook触发时机 / Called when可返回 / Can return
on_load()插件启用 / Plugin enabled—
on_unload()插件禁用 / Plugin disabled—
on_atc_response(text, action)每次 ATC 回复 / Every ATC reply修改后的文本或 None
on_telemetry(data)~10 Hz 遥测快照 / Telemetry snapshot—
on_frequency_change(freq)COM1 频率变化 / COM1 change—
on_pilot_input(text)LLM 处理前 / Before LLM修改后的文本或 None
on_cabin_media_play(media_id)用户播放客舱媒体 / Cabin media played—
插件 API / Plugin API
方法/属性说明 / Description
self.emit(event, data)推送 socket.io 事件到仪表盘
self.subscribe(event, cb)监听内部 EventBus 事件
self.shared_context共享状态只读快照
self.config插件自身配置字典
self.save_config()持久化配置到 plugin/config.json
self.log(msg)带插件前缀记录日志
